# TracerBuddy MVP

**TracerBuddy — The smarter way to track every shot.**

## Features

- Phone GPS shot tracking
- Hit Shot / Ball Found Here
- Live satellite map with Leaflet
- Start and end shot markers
- Gold dashed shot lines
- Current hole / full round map toggle
- Scorecard
- Stats and shot history
- Browser localStorage saving

## Deploy to Vercel

1. Unzip this folder.
2. Upload it to GitHub.
3. Go to Vercel.
4. Click **Add New Project**.
5. Import the GitHub repo.
6. Use these settings:
   - Framework Preset: **Vite**
   - Build Command: `npm run build`
   - Output Directory: `dist`
7. Deploy.

## Run locally

```bash
npm install
npm run dev
```

## iPhone use

Open the Vercel URL in Safari. Tap Share > Add to Home Screen.
Location/GPS requires HTTPS, which Vercel provides automatically.
